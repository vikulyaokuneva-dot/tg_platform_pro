# VK daily queue: безопасные изображения

`queue.json` — постоянное состояние ежедневной очереди. Оно хранится в Git и
не зависит от `actions/cache` или локального SQLite. Материал №29 уже отмечен
как опубликованный контрольный пост и не может быть выбран повторно.

Для боевой записи обязательно нужен локальный JPEG или PNG размером от 1 КБ до
10 МБ. У каждого элемента `media` должны быть все поля:

```json
{
  "license": "own",
  "rights_reference": "internal-rights-record-123",
  "path": "vk_daily/assets/example.jpg",
  "sha256": "<sha256 файла>"
}
```

Допустимые значения `license`: `own`, `licensed`, `generated`. `rights_reference`
— идентификатор внутренней записи о правах либо ссылка на лицензию; он не
выводится workflow. Изображения со страниц источников не загружаются и не
считаются лицензированными автоматически. При отсутствии любого поля материал
остаётся в очереди, а `wall.post` не вызывается.

Генератор изображений в репозитории не настроен. В этой версии не добавляется
ни платный API, ни новый Secret: допустим только уже разрешённый генератор,
результат которого сохранён как локальный файл с подтверждением прав.
