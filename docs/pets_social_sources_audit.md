# PETS 4.4 — исследование социальных площадок и бытовой проверки фактов

Дата фактических HTTP-проверок: 26.10.2026. Режим: только исследование. Ветка: `feat/pets-3-1-autonomous`.

## Честный итог

Практичный ежедневный поток можно собрать, но из двух разных слоёв:

1. Публичные Telegram-каналы дают достаточно **тем, вопросов и форматов**, но не становятся источником фактов.
2. Бытовые справочники помогают проверить обычные темы о содержании, породах, уходе и воспитании; при этом их тексты не копируются и не перерабатываются автоматически.
3. Медицинские, спорные и научные утверждения остаются в контуре factual brief: PMC/Frontiers и дополнительная редакционная проверка.

Ни один из результатов ниже не подключён к production PETS, не меняет `pets-state`, не вызывает GigaChat и не отправляет сообщений в Telegram.

## Метод и границы

Проверка Telegram — по одной публичной странице `https://t.me/s/<handle>` на источник, последовательно с паузой 1 секунду. Для каждой записи сохранены только URL, время, короткий фрагмент до 240 символов, признак текста/изображения и статус. Изображения не скачивались, полный текст постов не сохранялся.

Для VK, Дзена и Pinterest сделаны ограниченные публичные диагностические запросы. Вход, CAPTCHA, закрытые страницы, неофициальные API и обход ограничений не использовались. Нельзя честно назвать автоматический сбор этих площадок рабочим, пока он не получает реальные записи через документированный доступ.

Полный локальный диагностический результат Telegram находится в игнорируемом Git файле `runs/pets_4_4_social_sources/telegram_public_preview.json`; в нём нет токенов, персональных данных, фото и полного текста.

### Почему остальные платформы пока не проходят

* **VK:** мобильный поиск вернул HTTP 200 и 110 297 байт HTML, но извлекаемого списка постов наш ограниченный метод не подтвердил. Для следующего исследования нужен официальный доступ/API с отдельными учётными данными и проверкой прав, а не парсинг страницы.
* **Дзен:** публичный поисковый URL был перенаправлен в `sso.passport.yandex.ru`; результат не содержит доступной ленты. Авторизацию или обход не выполняли.
* **Pinterest:** публичный поиск досок вернул HTTP 200 и 1 569 151 байт клиентской оболочки, но не валидированный список досок/пинов. Официальный Pinterest API требует авторизации приложения и токена, включая scope `boards:read`/`pins:read` ([документация Pinterest](https://developers.pinterest.com/docs/getting-started/set-up-authentication-and-authorization/)).

| [Petstory](https://petstory.ru/) | 200, 201 598 байт, каталог статей | ручная проверка бытовой информации | сервис с коммерческими услугами; заявление о вет-проверке не делает источник независимым |

Все четыре сайта доступны без входа, но это не равно лицензии на автоматическое извлечение и переработку. В PETS допустимы: найти тему, прочитать вручную, записать свой проверенный factual brief и дать ссылку. Недопустимы: копировать статью, массово собирать тексты/фото, генерировать пост из одного брендового материала или выдавать его совет за независимый факт.

## Целевая политика источников

```text
Telegram / VK / Дзен / Pinterest
             -> только интересы аудитории и темы
             -> выбранная тема
справочник о быте / уходе
             -> ручная проверка и factual brief
PMC / Frontiers / профильный источник
             -> научные и медицинские утверждения + усиленная проверка
             -> оригинальный текст PETS
```

Рекомендуемый ежедневный процесс: выбрать одну новую тему из Telegram-очереди, исключить рекламу и медицинские обещания; для обычной темы проверить её по разрешённому справочнику и/или второму независимому источнику; для здоровья — использовать научный/авторитетный источник и направлять в `review`; только затем готовить оригинальный текст. Социальная публикация никогда не является источником факта.

## Семь переданных URL о собаках

В текущем репозитории, приложениях этого task и доступном рабочем контексте семи индивидуальных ссылок нет. Они отмечены в реестре как `pending_owner_resend`; я намеренно не подставлял похожие URL. После повторной отправки проведу для каждой отдельный HTTP/API-тест, извлеку только метаданные и добавлю решение «поиск идей / бытовая проверка / усиленная научная проверка / не использовать».

## Решение, требующее владельца

Не подключать ничего в production на этом этапе. Практическая следующая точка — подтвердить, разрешаете ли вы добавить Telegram-источники как **ручную очередь тем** (без фактов и без автоматической публикации), а также повторно передать семь URL для завершения их проверки.
