# AGRO → личный Telegram: черновик для VK

Это дополнение к существующему регулярному AGRO-проходу, а не новый VK
pipeline, workflow или расписание. Оно запускается только после успешного
`sendPhoto/sendMessage` в канал «Сад без хлопот» и не меняет редакционный
статус материала, VK Autopilot или VK Daily.

## Включение

По умолчанию функция выключена:

```text
AGRO_VK_DM_ENABLED=0
```

После проверки в GitHub добавьте:

- Repository variable `AGRO_VK_DM_ENABLED` = `1`;
- Repository secret `AGRO_VK_DM_CHAT_ID` = числовой ID личного чата.

Используется уже существующий `AGRO_BOT_TOKEN`. Владелец обязан сначала
открыть этого бота и нажать **Start**, иначе Bot API вернёт ошибку, а AGRO
публикация в канал всё равно останется успешной.

## Сообщение владельцу

Для текста используется существующий детерминированный `vk_autopilot`
редактор: он сохраняет факты, числа, рекомендации и строку `Источник:` из
проверенного AGRO-поста. Новый AI-вызов не выполняется.

Техническая/правовая заметка отправляется отдельно от текста для копирования.
Если итог помещается в Telegram caption, то он подписывает уже скачанное фото;
иначе фото и чистый VK-текст приходят отдельными сообщениями. Повторно изображение
не скачивается.

`VK_SOURCE_IMAGES_ALLOWED=1` — это существующее явное подтверждение прав на
повторную публикацию исходных изображений в VK. Пока флаг не установлен,
владелец получает фото только как ориентир и явное предупреждение: не
публиковать его в VK без разрешения. Никакого утверждения о наличии прав не
делается.

## Дедупликация

В `data/agro_channel.db` хранится минимальная таблица
`agro_vk_dm_deliveries` с уникальным `material_id` и состоянием `sending`,
`sent` или `failed`. Обычный повтор AGRO-задачи не сможет отправить тот же
материал повторно, включая случай Telegram API error. Повторная доставка —
только отдельное осознанное действие оператора (в этот проход не добавлялось).
