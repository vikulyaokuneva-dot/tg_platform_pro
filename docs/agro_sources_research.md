# Исследование источников для агро-канала

## 1. Введение

Цель исследования — определить, какие источники и механизмы текущей платформы можно переиспользовать для создания Telegram-канала на тему агро (сад, огород, фермерство, агротехнологии, бизнес).

## 2. Архитектура текущего проекта

Текущий pipeline состоит из следующих этапов:

1. **SOURCE** — источники контента.
2. **DISCOVERY** — поиск новых материалов.
3. **FETCH** — загрузка контента.
4. **EXTRACTION** — извлечение текста, изображений, метаданных.
5. **CLASSIFIER** — классификация контента.
6. **CASE/NEWS** — формирование кейсов/новостей.
7. **EVIDENCE** — подтверждение данных.
8. **POST** — генерация постов.
9. **Telegram publication** — отправка постов.

| Файл                          | Описание                                                                 |
|--------------------------------|----------------------------------------------------------------------------|
| `case_pipeline/config.py`      | Конфигурация источников, URL-шаблоны, параметры.                         |

## 5. Принципы классификатора для агро-канала

Классификатор должен проверять следующие критерии:

1. **Практическая польза**: Есть ли конкретные действия, которые может выполнить читатель?
2. **Конкретность**: Есть ли растение/культура/технология?
3. **Результат**: Есть ли измеримый результат (например, "увеличение урожая на 30%").
4. **Научная/официальная опора**: Есть ли ссылки на исследования или нормативные документы?
5. **Отсутствие рекламы/SEO-воды**: Нет ли явных рекламных сообщений или SEO-спамных текстов.
6. **Отсутствие новостного шума**: Не просто новость, а полезная информация.

## 6. Типы материалов для агро-канала

| Тип материала          | Обработка                                                                 |
|-------------------------|---------------------------------------------------------------------------|
| **Практический совет**  | Прямо в основной поток.                                                  |
| **Новость без практики**| В отдельный News lane или на фактчекинг.                                  |
| **Реклама/SEO**         | Отбрасывать.                                                              |
| **Научные исследования**| В фактчекинг или отдельную рубрику.                                      |
| **Нормативные документы**| В рубрику "Экономика" или "Практика".                                    |

## 8. Рекомендуемый стартовый набор источников

### Tier A (основной поток)

1. **Ботаничка** (5/5 по relevance и signal).
2. **Своё Фермерство** (5/5 по relevance и практичности).
3. **Gismeteo** (4/5 по relevance, но полезен для погоды).
4. **Агроинвестор** (4/5 по relevance, но требует фильтрации новостей).

### Tier B (дополнительный радар)

1. **Direct.Farm** (3.8/5, но сложно автоматизировать).
2. **Landshaft** (4/5, но меньше контента по фермерству).

### Tier C (фактчекинг)

1. **Россельхозцентр** (нормативы).
2. **Госсорткомиссия** (сорта растений).

### Tier D (ручной/экспериментальный)

1. **Reddit**, **ForumHouse**, **TikTok** (сложно автоматизировать).

## 9. Рекомендуемый pipeline для агро-канала

```
SOURCE (Агроинвестор, Ботаничка, Gismeteo, Своё Фермерство)
→ DISCOVERY (конфигурация источников)
→ FETCH (парсинг)
→ EXTRACTION (извлечение текста, изображений)
→ AGRO CLASSIFIER (фильтрация по тегам, отбраковка шума)
→ EVIDENCE (фактчекинг для нормативных источников)
→ EDITORIAL (ручная проверка, если нужно)
→ POST (генерация постов с агро-шаблонами)
→ TELEGRAM (отправка в агро-канал)
```

## 10. Рекомендуемый следующий шаг

1. **Создать конфигурацию для агро-источников** в `config.py`.
2. **Добавить агро-теги в classifier_lib.py**.
3. **Настроить фактчекинг для нормативных источников**.
4. **Создать агро-шаблоны для генерации постов**.
5. **Настроить отправку в новый Telegram-канал**.

## 11. Заключение

Текущая платформа уже поддерживает основные механизмы для добавления нового канала. Необходимо:

- Добавить конфигурацию для агро-источников.
- Настроить классификатор для фильтрации агро-контента.
- Создать шаблоны для генерации постов.
- Настроить отправку в новый Telegram-канал.

Это позволит запустить агро-канал без изменения общего рабочего ядра платформы.
