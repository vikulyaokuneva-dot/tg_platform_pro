# TG Platform Pro — автопостинг новостей в Telegram

Платформа автоматически собирает **свежие** статьи из HTML-источников, перерабатывает их с помощью **GigaChat**
(перевод EN→RU + заголовок/саммари/хэштеги) и публикует в **любое количество** Telegram-каналов.

Режим работы по умолчанию:
- GitHub Actions запускает `run_once.py` 3 раза в день (09:00 / 13:00 / 18:00 по Москве, UTC+3)
- в каждый канал публикуется **ровно 1** свежая статья (TTL 12 часов)
- ошибки не валят процесс: проблемные статьи/источники пропускаются

## Функциональность

- Автоматическая публикация статей несколько раз в день
- Поддержка до 50 чат-каналов на разные темы
- Индивидуальная настройка каждого канала (источники, ключевые слова, стиль подачи)
- Защита от дублирования публикаций
- Адаптация к изменениям в структуре сайтов
- Обработка ошибок без остановки работы
- Ведение логов
- Поддержка разных стилей подачи материала
- Автоматическое добавление хэштегов к статьям в зависимости от тематики канала
- Веб-интерфейс для управления ботом

## Запуск локально (для проверки)

1. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

2. Экспортируйте переменные окружения (или задайте их в Secrets GitHub):
   - `POSTER_BOT_TOKEN`
   - `GIGACHAT_API_KEY`
   - `*_CHAT_ID` для каждого канала (см. `config.py`)

3. Запустите:
   ```
   python run_once.py
   ```

База SQLite хранится в `data/bot.db` (в GitHub Actions она сохраняется через cache).

## Настройка каналов и источников

Настройки берутся из `config.py`:
- `CHANNEL_IDS` — соответствие ключа канала и `*_CHAT_ID` из Secrets
- `HTML_SOURCES` — список источников по каждому каналу (url + CSS селектор ссылок)
- `CHANNEL_BASE_HASHTAGS` — базовые хэштеги канала, которые добавляются к тем, что вернёт GigaChat

Расписание GitHub Actions находится в `.github/workflows/publisher.yml`.

> Примечание: файлы `channels_config.json`, `channels_hashtags_config.json` и `web_interface.py` сейчас считаются
> **legacy** (исторические). Ядро продакшн-запуска использует `config.py` + Secrets GitHub.

```json
{
  "channels": {
    "ID_КАНАЛА": {
      "sources": [
        "https://пример-сайта.com"
      ],
      "keywords": [
        "ключевое_слово1",
        "ключевое_слово2"
      ],
      "style": "neutral"
    }
  }
}
```

Где:
- `ID_КАНАЛА` - числовой идентификатор канала (его можно получить у @userinfobot)
- `sources` - список URL-адресов источников новостей
- `keywords` - ключевые слова для фильтрации статей
- `style` - стиль подачи материала (neutral, informal, formal, promotional)

### Стили подачи материала

- `neutral` - нейтральный стиль
- `informal` - неформальный стиль с эмодзи и хэштегами
- `formal` - формальный стиль с указанием источника
- `promotional` - продающий стиль с призывами к действию

## Навигация по каналам через хэштеги

Новая функция позволяет автоматически добавлять хэштеги к публикуемым статьям. Каждый канал имеет свои уникальные хэштеги, которые отражают его тематику. Это упрощает навигацию по каналу и помогает пользователям быстрее находить интересующий контент.

Для настройки хэштегов используется файл `channels_hashtags_config.json`, где к каждому каналу можно добавить список хэштегов:

```json
{
  "channels": {
    "ID_КАНАЛА": {
      "sources": [
        "https://пример-сайта.com"
      ],
      "keywords": [
        "ключевое_слово1",
        "ключевое_слово2"
      ],
      "style": "neutral",
      "hashtags": [
        "#хэштег1",
        "#хэштег2",
        "#хэштег3"
      ]
    }
  }
}
```

Примеры хэштегов:
- IT и программирование: #python, #programming, #coding, #developer
- Бизнес: #business, #startup, #entrepreneur
- Садоводство: #садоводство, #огород, #посев, #посадка

## Веб-интерфейс

Для управления ботом доступен веб-интерфейс:

1. Запустите веб-интерфейс:
   ```
   python web_interface.py
   ```

2. Перейдите по адресу http://localhost:5000

Через веб-интерфейс можно:
- Добавлять и удалять каналы
- Изменять настройки каналов
- Просматривать логи работы бота

## Запуск бота

```
python main.py
```

## Архитектура

Проект состоит из следующих компонентов:

- `main.py` - основной файл запуска и планировщик публикаций
- `telegram_bot.py` - работа с Telegram API
- `parser.py` - модуль парсинга статей с сайтов
- `processor.py` - обработка и сокращение статей
- `database.py` - управление базой данных (история публикаций, логи ошибок)
- `config.py` - конфигурационные параметры
- `web_interface.py` - веб-интерфейс для управления ботом
- `channels_config.json` - конфигурация каналов
- `bot_database.db` - база данных SQLite

## Безопасность и надежность

- При возникновении ошибок процесс не падает, а делает пропуск и продолжает работу с записью ошибки в логах
- Защита от дублей реализована через базу данных
- Механизмы повторных попыток при ошибках отправки в Telegram
- Адаптация к изменениям в структуре сайтов через гибкие селекторы
