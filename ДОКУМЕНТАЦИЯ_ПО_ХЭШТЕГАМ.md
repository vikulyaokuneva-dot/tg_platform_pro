# Документация по системе навигации по каналам через хэштеги

## Общее описание

Система позволяет автоматически добавлять хэштеги к публикуемым статьям в зависимости от канала. Каждый канал имеет свой уникальный набор хэштегов, который отражает его тематику и помогает пользователям ориентироваться в контенте.

## Структура конфигурационного файла

Файл `channels_hashtags_config.json` содержит информацию о каждом канале, включая:

- `sources` - список источников новостей
- `keywords` - ключевые слова для фильтрации
- `style` - стиль подачи материала
- `hashtags` - список хэштегов, которые будут добавлены к каждой статье

## Категории хэштегов по тематикам каналов

### IT и программирование
Пример хэштегов: `#python`, `#programming`, `#coding`, `#developer`, `#tech`, `#software`, `#development`, `#IT`

### Бизнес и стартапы
Пример хэштегов: `#business`, `#startup`, `#entrepreneur`, `#innovation`, `#marketing`, `#finance`, `#investing`, `#success`

### Садоводство и огородничество
Пример хэштегов: `#садоводство`, `#огород`, `#посев`, `#прикормка`, `#болезни`, `#урожай`, `#семена`, `#удобрения`, `#полив`, `#посадка`

### Здоровье и медицина
Пример хэштегов: `#здоровье`, `#медицина`, `#фитнес`, `#питание`, `#лечение`, `#профилактика`, `#витамины`, `#упражнения`

### Кулинария
Пример хэштегов: `#рецепты`, `#кулинария`, `#еда`, `#готовка`, `#вкусно`, `#домашняякухня`, `#ингредиенты`, `#приготовление`

## Как добавить новый канал с хэштегами

Для добавления нового канала с уникальной системой хэштегов, добавьте запись в файл `channels_hashtags_config.json` в следующем формате:

```json
"-100XXXXXXXXXX": {
  "sources": [
    "https://example-source.com"
  ],
  "keywords": [
    "keyword1",
    "keyword2"
  ],
  "style": "neutral",
  "hashtags": [
    "#хэштег1",
    "#хэштег2",
    "#хэштег3"
  ]
}
```

## Работа системы

1. При публикации статьи система определяет, к какому каналу она относится
2. Из конфигурационного файла извлекаются соответствующие хэштеги для этого канала
3. Хэштеги автоматически добавляются в конец текста статьи перед публикацией
4. Система учитывает ограничение на длину сообщения в Telegram (4096 символов) и при необходимости обрезает основной текст, чтобы вместить хэштеги

## Примечания

- Все хэштеги начинаются с символа `#`
- Количество хэштегов для каждого канала может варьироваться
- Хэштеги добавляются в виде строки через пробел после основного текста статьи
- Система проверяет, не превышает ли общая длина сообщения допустимый лимит, и при необходимости корректирует содержимое
