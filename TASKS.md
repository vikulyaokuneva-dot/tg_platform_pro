# Задачи — Telegram Platform

## Backlog

### Ручной заказ поста через Telegram-бота с согласованием

**Статус:** новая идея / не начинать без отдельного решения.

**Цель:** владелец задаёт тему сообщением существующему Telegram-боту. Бот ищет материал только в разрешённых и доступных для выбранного канала источниках, готовит черновик и отдаёт его владельцу на согласование. Публикация в канал возможна только после явного действия владельца.

**Целевой сценарий:**

1. Владелец пишет боту тему и выбирает целевой канал, если их несколько.
2. Бот подбирает подтверждённые источники, уже доступные этому каналу; не запускает отдельный регулярный pipeline и не публикует автоматически.
3. Бот готовит черновик: заголовок, текст, ссылку(и) на первоисточник и изображение только при подтверждённых правах на его использование.
4. Бот присылает черновик в личный чат владельца с действиями **«Опубликовать»** и **«Редактировать»**.
5. При «Редактировать» владелец отправляет правки или новый текст; бот показывает обновлённый черновик для повторного явного подтверждения.
6. При «Опубликовать» бот отправляет согласованную версию в выбранный Telegram-канал ровно один раз и сохраняет результат доставки.

**Границы и требования:**

- доступ только владельцу/разрешённым администраторам;
- использовать существующего бота и существующие источники/редакционные правила канала;
- не выполнять повторный поиск или генерацию после нажатия «Опубликовать»;
- дедупликация по черновику и подтверждённой публикации, чтобы повторное нажатие не создавало дубль;
- ошибка подготовки или личной отправки не должна менять регулярные AGRO, PETS и другие pipeline;
- не включать новые расписания, GitHub Actions или автопубликацию;
- техническая информация о поиске и доставке не должна попадать в копируемый текст поста.

**Перед реализацией уточнить:** список каналов первого релиза, перечень разрешённых источников для каждого канала, формат редактирования и идентификаторы администраторов.

**Критерий готовности:** после явного подтверждения владельцем в личном чате согласованный пост публикуется один раз в выбранном канале; без подтверждения черновик остаётся непубликованным.
